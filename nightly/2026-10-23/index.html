Run hygiene

The ROCm prefix, the dataset and this repository are mounted read-only; suites write only to their output directory.

LMDB datasets are used through private copies (M14); scripts that write into their working directory run in scratch directories.

Every container sees only the tested GPU; no shipped script that calls sudo or rm -rf is run.
